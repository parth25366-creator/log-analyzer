# Log Analyzer 🔍

A cybersecurity tool that analyzes server logs to detect suspicious activity like brute force attacks, port scans, and unusual IP patterns.

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Analysis:** Custom log parsing + pattern detection

## Features (planned)
- Upload Apache/Nginx/SSH log files
- Detect brute force login attempts
- Flag suspicious IPs
- Visualize alerts on a dashboard
- Export findings as report
